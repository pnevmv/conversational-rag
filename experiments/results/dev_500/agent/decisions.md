# Step 8: decisions

Rules were fixed before the runs (plan approved on 2026-10-29). The tables are in `a1_summary.json` (generated by `experiments/agent.py report`); this file is written by hand.

## A1 (fixed controller): negative on dev-500, no full-validation run

dev-500, gpt-5.4-nano, baseline E with citations. Spend of the A1 runs: about USD 1.0.

* **The sufficiency check works as a classifier.** Against "gold section in context" (answerable questions, passages or facts) Youden's J is 0.33 [0.23, 0.42], so the gate (J ≥ 0.2, lower bound above 0) is passed. "Sufficient": precision 0.86, recall 0.63; "insufficient": precision 0.39 (base rate of missing gold 25%), recall 0.70. On the 31 unanswerable questions it says insufficient in 58%. Parse failures: 2 of 500.
* **The extra round does not find the gold section.** 231 of 500 questions (46%) took it. On the 213 answerable ones the new query alone puts a gold section in its top 5 less often than E's query (45.5% against 53.5%), and adding its sections to E's top 5 raises passage recall only from 53.5% to 59.2% (+5.6 points); gold in the whole context (passages or facts) goes from 61.0% to 65.7%.
* **F1 does not improve.** Against E: −0.6 on all questions [−1.6, 0.4], +0.1 on answerable ones [−0.5, 0.6], −1.2 on the questions that took the round [−3.5, 1.0]. The larger context makes G0 abstain less: abstain recall 32.3% against 41.9% for E (31 unanswerable questions, noisy), false abstention unchanged (4.5%).
* **Own refusal (refuse if the second check is still insufficient) is worse:** −6.6 on all questions [−8.5, −4.7]; the second check says insufficient for 80% of the round questions and false abstention reaches 37%. Abstain(G0) stays the default, as in the plan.
* **Cost:** USD 2.29 per 1,000 turns against 1.39 for E (+65%), 2.9 model calls per turn against 1.9.
* **Decision:** A1 can only be kept with the interval of Δ F1 on all questions above 0 (it costs more than E by construction). With Δ = −0.6 [−1.6, 0.4] on dev-500 at +65% cost it cannot reach that, so A1 is not run on the full validation split. Reported as a negative result: the check can tell when the context lacks the gold section, but a second search with the model's own query does not repair it.
